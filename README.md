# Greyhollow

A third-person survival horror set in an original parish. Over-the-shoulder aiming, scarce ammunition, a locked barn, a cellar brazier puzzle, and a chapel warden.

## Run

```bash
npm install
npm run dev
```

The game is served with the rest of the site. Click **New Game**.

## Controls

- WASD or arrows — move (camera-relative)
- Mouse — aim (pointer lock; right-drag if the browser blocks capture)
- Left click — fire
- R — reload
- F or right click while captured — knife
- Space — dodge
- Shift — sprint
- E — use
- Tab — pack
- 1 / 2 or wheel — weapons
- Esc — pause

Touch devices get a stick, a look pad, and action buttons.

Progress is stored in local storage at field radios.
